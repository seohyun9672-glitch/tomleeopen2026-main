# Whyte Inktrap font

Place Whyte Inktrap WOFF2 files here so the site can use them:

- `WhyteInktrap-Regular.woff2` (weight 400)
- `WhyteInktrap-Medium.woff2` (weight 500)
- `WhyteInktrap-Bold.woff2` (weight 700)

Whyte Inktrap is available from [Dinamo](https://abcdinamo.com/) (paid). If you don’t add these files, the site will fall back to the system font.
